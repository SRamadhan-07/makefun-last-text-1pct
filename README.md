A tiny Python program that writes one final text message — sent by a dying
phone at 1% battery, in the phone's own voice — to `/output/entry.txt`.
The phone flips the classic late-night "u up?" text on its head, then signs
off by claiming it died doing what it loved: ignoring low battery warnings.

## How to run

```sh
python3 main.py
```

This creates `/output` if needed and writes the entry text to
`/output/entry.txt`, exactly as-is, with nothing else printed.
